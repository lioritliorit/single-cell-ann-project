## 四、新增功能测试方法

### 测试前准备

```bash

cd 项目目录
PORT=5001 python app.py
# 浏览器打开 http://127.0.0.1:5001
```

### 4.1 可视化散点图测试

```
测试步骤：
1. 打开页面 → 可视化区域可见 PCA 散点图（69032个点）
2. 切换"着色方式"为 疾病状态 / 数据分组 → 颜色重新映射
3. 在"细胞类型筛选"选择一个类型 → 只显示该类型细胞
4. 鼠标滚轮缩放、拖拽平移 → 交互正常
5. 点击 UMAP 标签页 → 切换至 UMAP 散点图（5000个点）
6. 点击"重置视图" → 回到自动缩放状态
```

**预期结果：** 散点图渲染流畅，交互操作响应正常，UMAP/PCA 切换正确。

### 4.2 点击/框选检索测试

```
测试步骤：
1. 在散点图上单击任意一个点 → 底部出现"选中细胞"信息条

2. 点击选中信息条的"检索相似细胞"按钮

   ✓ 检索区域的细胞ID输入框已填入对应 cell_id
   ✓ 自动提交检索，显示 Top-K 结果
3. 使用套索选择（Lasso Select）框选一片区域
   ✓ 显示首个选中细胞的信息
   ✓ 点击"检索相似细胞"同样有效
```

**预期结果：** 从散点图到检索的闭环流程畅通，不会出现"请输入细胞 ID"错误。
